# Multi-Robot Research Notes

Working notes and drafts on prediction, coordination, and runtime assurance in multi-robot systems.

| Directory | Contents |
| --- | --- |
| [`onboard-prediction-notes/`](onboard-prediction-notes/) | Notes on running prediction on board and on what happens to a prediction as it moves along the multi-robot command path |
| [`predictive-vs-reactive-rta/`](predictive-vs-reactive-rta/) | Draft study of when a predictive runtime-assurance trigger outperforms a tuned reactive margin |

Each draft builds with `pdflatex`, `bibtex`, and two further `pdflatex` passes on its main file (`main.tex` or `paper.tex`).
