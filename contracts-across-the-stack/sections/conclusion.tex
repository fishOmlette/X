\section{Conclusion}
\label{sec:conclusion}

Existing work provides substantial machinery for mission specification,
component verification, dynamical composition, monitoring, and safety fallback,
but each approach class makes at most two of seven interface obligations
explicit, and none makes lifecycle explicit.  Guarantees therefore become hard
to connect where they protect different objects or leave interface assumptions
implicit.  The interface-contract framework organizes the recurring obligations,
distinguishes intra-robot from inter-robot interfaces, and gives them
three-valued admission and recovery semantics.  For peer state, the temporal
admission margin shows that event time, clock error, and estimation error are
necessary interface fields and prices the choice between on-board and remote
inference.  The framework remains a reference model: formal instantiation and
evaluation on multi-robot systems are required before it can support a
reliability claim.
