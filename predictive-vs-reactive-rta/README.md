# When Does Predicting Failure Help?

Manuscript, simulators, tests, result records, and figure pipeline for:

> M. A. Farooq, "When Does Predicting Failure Help? A Boundary Analysis of Predictive versus Reactive Runtime Assurance for Multi-Robot Coordination," manuscript in preparation.

**Read the paper:** [predictive-vs-reactive-rta.pdf](predictive-vs-reactive-rta.pdf)

## Summary

**Question.** A predictive runtime-assurance trigger fires when the projected time to margin expiry falls below a horizon. A reactive trigger can also act early by using a larger fixed margin. When does prediction offer something a tuned fixed margin cannot?

**Analysis.** In an idealized timing model, the predictive trigger is a current-margin threshold whose pad scales with the estimated degradation rate. Earlier action changes the recovery outcome only within a band set by recovery duration and deadline slack, and observation age consumes that band one for one. The minimal predictive horizon wastes less lead than the minimal safe fixed pad when recovery needs a similar *time* in every case but, because degradation rates differ, a different *margin*.

**Evidence.** Kinematic simulations with equal tuning budgets and seed-disjoint tuning and testing:

- Two-robot single-margin study: the tuned fixed rule records 0/6,750 held-out conflict collisions and the tuned predictive rule 2/6,750, so no timing inference is drawn.
- Three-robot shared-zone study: untreated trajectories always collide; both tuned rules succeed in 1,620/1,620 held-out conflict episodes, and prediction shortens mean makespan by 2.779 s (paired 95% bootstrap interval [2.659, 2.902] s) while serializing far fewer clear paths.

The results are conditional on the simulated scenario grids and do not establish real-world safety. Experiments on ROS 2 with the Nav2 navigation stack are future work.

## Reproduce the experiments

From this directory in Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r code\requirements.txt
.\.venv\Scripts\python -m unittest discover -s tests -v

.\.venv\Scripts\python code\single_margin_experiment.py
.\.venv\Scripts\python code\stress_tests.py
.\.venv\Scripts\python code\heldout_evaluation.py
.\.venv\Scripts\python code\coordination_experiment.py
.\.venv\Scripts\python code\generate_figures.py
```

The held-out evaluations take several minutes. Every script resolves its paths relative to this directory. Tables II and III report values from `results/heldout_evaluation.json` and `results/coordination_validation.json`; the figures are regenerated from the simulators.

## Build the paper

From the repository root:

```powershell
python tools/paper.py build predictive-vs-reactive-rta     # main.pdf
python tools/paper.py package predictive-vs-reactive-rta   # dist/predictive-vs-reactive-rta-arxiv-source.zip
```

Or, in this directory: `pdflatex main`, `bibtex main`, `pdflatex main`, `pdflatex main`.
