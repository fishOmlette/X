# When Does Predicting Failure Help?

My timing analysis and simulation experiments on when prediction helps:

> M. A. Farukh, "When Does Predicting Failure Help? A Boundary Analysis of Predictive versus Reactive Runtime Assurance for Multi-Robot Coordination".

**Read the research note:** [predictive-vs-reactive-rta.pdf](predictive-vs-reactive-rta.pdf)

## The question and approach

**Question.** Prediction can tell a robot to act before its safety margin runs out. A fixed threshold can also make it act early. When does prediction add something beyond choosing a more conservative threshold?

**What the model shows.** The predictive trigger acts like a fixed threshold with a buffer that changes with the estimated rate of decline. Acting earlier helps when it gives recovery enough time to finish before the deadline. Old observations use up that extra time one for one. Adapting the buffer can avoid unnecessary waiting when recovery needs similar lead times across cases but the margins decline at different rates.

**What happened in the simulations.** I gave both rules the same tuning budget, then tested them with new noise seeds:

- **Three robots sharing a zone:** both tuned rules completed all 1,620 conflict episodes successfully. Prediction cut mean completion time by 2.779 s (paired 95% bootstrap interval [2.659, 2.902] s). On clear paths, unnecessary serializations fell from 1,080 to 21 out of 1,620 episodes. Without intervention, every conflict run collided.
- **Two robots at a crossing:** the fixed rule recorded 0 collisions in 6,750 conflict episodes; prediction recorded 2. I report the successful-run times, but do not use them to claim an efficiency gain when the failure outcomes differ.

Next, I want to try these ideas with ROS 2 and Nav2.

## Reproduce the experiments

From this directory in Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r code\requirements.txt
.\.venv\Scripts\python -m unittest discover -s tests -v

.\.venv\Scripts\python code\single_margin_experiment.py
.\.venv\Scripts\python code\stress_tests.py
.\.venv\Scripts\python code\heldout_evaluation.py
.\.venv\Scripts\python code\coordination_experiment.py
.\.venv\Scripts\python code\generate_figures.py
```
